01指针 Pointer 内存地址与间接访问

指针是 C++ 里最核心也最容易踩坑的概念。理解它的关键是：指针本身也是一个变量，只不过它存的值是"内存地址"。把内存想象成一排带编号的格子，变量是格子里的东西，指针就是一张写着格子编号的纸条。

什么是指针

一个变量由三部分组成：地址（它在内存中的位置）、类型（它占多大空间、怎么解释）、值（里面存的数据）。指针变量保存的"值"就是另一个变量的地址。

C++
int x = 42;      // 普通变量：内存中有一块区域存着 42
int* p = &x;    // p 是指针变量，& 取地址 —— p 存的是 x 的地址
                 // 读法：p 是"指向 int 的指针"

std::cout << p;   // 输出一个地址（形如 0x7ffeefbff5ac）
std::cout << *p;  // * 是解引用：顺着地址找到那个格子，输出 42

*p = 100;        // 通过指针修改 x 的值
std::cout << x;  // 100 —— x 真的被改了
✓
类比记忆

int x 是"一间屋子"，&x 是"屋子的门牌号"，int* p 是"一张写着门牌号的纸条"，*p 是"按纸条上的门牌号走进屋子"。指针存地址、解引用取内容，两者是一对操作。

空指针与野指针

空指针（nullptr）：不指向任何对象的指针，用 nullptr 表示（C++11 起，替代老式的 NULL 或 0）。对空指针解引用是未定义行为，使用前必须判空。

野指针：指向"已失效内存"的指针——要么从未初始化，要么指向的内存已被释放。这是 C/C++ 程序崩溃的头号元凶。

C++
int* p = nullptr;        // 好习惯：先初始化为空指针
if (p) {                 // if (p) 等价于 if (p != nullptr)
    *p = 1;              // 只有非空才解引用，安全
}

int* q;                  // 错误示范：未初始化，q 的值是"垃圾地址"
                         // 它可能碰巧指向任何地方，解引用是灾难

int* r = new int(5);
delete r;                // 释放 r 指向的内存
r = nullptr;             // 释放后立即置空，防止成为悬垂指针（dangling pointer）
!
悬垂指针

指针指向的内存被 delete 或 free 释放后，指针仍然"记得"那个地址，但它指向的对象已经不存在了。解引用悬垂指针是未定义行为（可能崩溃、可能读到垃圾值）。

指针与数组

数组名在大多数表达式中会退化为指向首元素的指针。数组和指针关系极为密切：下标操作 arr[i] 本质就是 *(arr + i)。

C++
int arr[5] = {10, 20, 30, 40, 50};
int* p = arr;            // arr 退化为 &arr[0]，p 指向第一个元素
std::cout << *p;         // 10
std::cout << p[2];       // 30 —— 指针也能用下标
std::cout << *(p + 3);   // 40 —— 下标就是解引用的语法糖
std::cout << arr[3];     // 40

// 数组指针（指向整个数组的指针，行指针）
int matrix[2][3] = {{1,2,3},{4,5,6}};
int (*prow)[3] = matrix; // prow 指向"含 3 个 int 的一行"
(*prow)[1]               // 2：第一行的第 2 个元素
*(*(prow + 1) + 2)       // 6：第二行第三列
!
区分三样东西

int* p[3]：指针数组，含 3 个 int* 元素的数组；int (*p)[3]：数组指针，指向含 3 个 int 的数组；sizeof(arr)：对数组名求大小是整个数组的字节数，但数组作为函数参数传入后就成了指针，sizeof 只会得到指针大小（8 字节）——这是经典面试坑。

指针运算

指针的加减法以它所指向的类型大小为单位。对 int* 加 1，地址实际增加 sizeof(int)（通常 4）字节。指针只在数组内加减才有意义。

C++
int arr[5] = {10, 20, 30, 40, 50};
int* p = arr;

p++;                  // 指向下一个元素（地址 +4 字节）
std::cout << *p;       // 20

p += 2;               // 再前进 2 个元素
std::cout << *p;       // 40

int* q = arr + 4;     // 指向最后一个元素
std::cout << (q - p); // 2 —— 指针相减得到"间隔的元素个数"

int* end = arr + 5;   // 尾后指针：指向数组最后一个元素的下一位
                      // 合法用于比较，但绝不能解引用

// 遍历数组的经典写法
for (int* it = arr; it != arr + 5; ++it) {
    std::cout << *it << " ";
}
i
指针运算 ≠ 整数运算

指针比较大小（< >）只对同一个数组内的指针有意义；不同数组的指针相减或比较是未定义行为。字符串字面量的比较也是经典陷阱："abc" == "abc" 比较的是地址而不是内容。

指针与函数

指针有三种常见用法：按指针传参（修改实参 / 避免拷贝）、函数指针（把函数当作值传递）、返回指针（动态分配的对象）。

C++
// ① 按指针传参：可以修改调用者的变量
void swap(int* a, int* b) {
    int t = *a; *a = *b; *b = t;
}
int x = 1, y = 2;
swap(&x, &y);            // x=2, y=1

// ② 函数指针：指向函数的指针
int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }

int (*op)(int, int) = add;   // op 是指向"int(int,int)"函数的指针
std::cout << op(3, 4);       // 7 —— 通过指针调用
op = sub;
std::cout << op(3, 4);       // -1

// ③ 返回指针（指向堆上对象）
int* makeInt(int v) {
    return new int(v);       // new 出来的对象不会随函数结束而消失
}

// ④ 数组作为参数退化为指针，必须额外传长度
void printArray(int* arr, int n) {
    for (int i = 0; i < n; ++i) std::cout << arr[i] << " ";
}
✓
回调与 C 接口

函数指针常用于"回调"（把处理逻辑交给另一个函数执行）。C++ 里更现代、更安全的替代是 std::function 和 lambda 表达式（见第 05 章）。

const 与指针（const 的位置决定一切）

读法口诀：const 修饰谁，谁就不可变。看 * 的位置：const 在 * 左边修饰"指向的对象"，在 * 右边修饰"指针本身"。

写法含义能做什么 / 不能做什么
const int* p指向 const int 的指针（底层 const）不能通过 *p 改值；但 p 本身可以重新指向别的对象
int* const p常量指针，指针本身是 const（顶层 const）p 初始化后不能再指向别处；但 *p 指向的值可以修改
const int* const p两者都不可变指针和指向的值都不能改
口诀："先看 const 离谁近，const 左边近 * 是对象、近名字是指针"。
C++
int a = 1, b = 2;
const int* p1 = &a;   // 指针可变，指向的值只读
p1 = &b;             // 合法：p1 改指 b
// *p1 = 10;         // 非法：不能通过 p1 修改

int* const p2 = &a;  // 指针本身是常量
*p2 = 10;            // 合法：值可以改
// p2 = &b;         // 非法：p2 不能重新指向

const int* const p3 = &a;  // 全都不能改

// 安全级别转换（重点！）
const int* cp = &a;  // 合法：int* 可以转成 const int*
// int* p = cp;      // 非法：去掉 const 限制是不允许的
const_cast<int*>(cp);  // 强制去掉 const（只有确定对象本身可变时才安全）

多级指针

指针可以指向指针。几颗 * 就代表几级间接：int** pp 读作"指向 int 指针的指针"，常用于在函数里修改调用者的指针变量、或表示二维的指针结构。

C++
int x = 10;
int* p = &x;      // 一级：p → x
int** pp = &p;    // 二级：pp → p → x

std::cout << **pp; // 10 —— 解引用两次
**pp = 99;        // 通过两级指针修改 x
std::cout << x;   // 99

// 典型用途：在函数内部修改外部的指针变量
void alloc(int** out) {
    *out = new int(42);   // 修改调用者传进来的指针
}
int* q = nullptr;
alloc(&q);               // 现在 q 指向 new 出来的 42
delete q;

指针常见陷阱

!
陷阱一：未初始化就解引用

局部指针变量如果不初始化，它的值是随机的。直接 *p = 1 可能写坏任意内存。习惯：声明时一律 = nullptr。

!
陷阱二：释放后继续用

delete 之后指针还残留旧地址，再次使用就是悬垂指针。习惯：释放后立刻 p = nullptr。

!
陷阱三：重复释放（double free）

同一块内存被 delete 两次会导致堆损坏甚至程序崩溃。两个指针指向同一块内存时极易发生。

!
陷阱四：越界访问

arr[5]（下标越界）在 C++ 里不报错也不提醒，只会静默踩坏相邻内存——这比崩溃更危险，因为错误可能过很久才暴露。

!
陷阱五：返回局部变量的地址

函数内的局部变量在函数返回时销毁，把它的地址返回出去就是悬垂指针。要么 new 到堆上，要么返回值本身。

✓
治本之策

现代 C++ 推荐用 引用（第 02 章）替代指针传参，用 智能指针（第 03 章）替代裸指针管理内存，用 迭代器（第 04 章）替代裸指针遍历容器。裸指针留给"必须指向且不拥有"的场景。

02引用 Reference 变量的别名

引用（reference）是已存在变量的别名。它不是一个新变量，不给对象分配新内存，而是"同一个格子的另一个名字"。引用让代码读起来像普通变量，行为却能达到指针的间接效果。

引用的规则

  • 必须初始化：定义引用时必须绑定一个对象，不存在"空引用"。
  • 不可重新绑定：引用一旦绑定一个变量，终生绑定它，不能改绑别的对象。
  • 不占独立内存：对引用取地址 &r 得到的是被绑定变量的地址（实现上可能占空间，但语言层面不可见）。
  • 引用不是对象，因此没有"引用的数组"，也不存在"指向引用的指针"。
C++
int x = 10;
int& r = x;        // r 是 x 的别名
r = 20;            // 等价于 x = 20
std::cout << x;     // 20
std::cout << &r;    // 与 &x 完全相同的地址

// int& bad;       // 错误：引用必须初始化
// int& r2 = x; r2 = 别的变量? —— 不行，赋值只是把值赋过去，绑定不变
int y = 5;
r = y;             // 合法，但这是"把 y 的值赋给 x"，r 仍然绑定 x

引用作函数参数（传引用）

传引用有两个作用：① 修改实参（替代指针）；② 避免拷贝（大对象直接传值会复制整份数据，性能差）。

C++
// 作用一：修改实参 —— 写法比指针干净
void swap(int& a, int& b) {
    int t = a; a = b; b = t;
}
int x = 1, y = 2;
swap(x, y);          // 调用时不需要取地址，函数内部直接改 x、y

// 作用二：避免拷贝 —— 传大对象
struct BigData { int data[10000]; };
void process(const BigData& bd) {   // const 引用：只读 + 零拷贝
    // 只读访问 bd
}
// 如果传值：每次调用都要复制 40000 字节，浪费内存和时间
!
何时用引用、何时用值

需要修改实参 → 传 T&；只需读取且对象大 → 传 const T&；对象很小（int、double、指针）且无需修改 → 直接传值，避免引用引入的别名开销与复杂度。

引用作返回值

返回引用可以避免返回时复制大对象，还能让函数返回"可被赋值的左值"，典型例子是容器的 operator[] 和 std::map::operator[]。但绝不能返回局部变量的引用。

C++
#include <vector>

int& get(std::vector<int>& v, std::size_t i) {
    return v[i];           // 返回容器中元素的引用
}
std::vector<int> v = {1, 2, 3};
get(v, 1) = 100;           // 直接通过返回值修改元素，v 变为 {1,100,3}
int x = get(v, 0);         // 拷贝一份出来也行

// 错误示范：返回局部变量的引用
int& bad() {
    int local = 5;
    return local;          // local 在函数结束时销毁，引用悬垂！
}                          // 任何使用都将是未定义行为

常量引用（const T&）

const T& 是最常用的引用形式：能绑任何东西（变量、临时对象、字面量），且保证不修改。它还有一个特殊能力：延长临时对象的生命周期。

C++
double pi = 3.14;
const double& r1 = pi;     // 绑定变量
const double& r2 = 2.71;   // 绑定字面量：临时对象会活到引用消亡
const int& r3 = 42;        // 合法；int& r4 = 42; 则非法

std::string makeStr() { return "hello"; }
const std::string& s = makeStr();   // 临时 string 的寿命被延长
std::cout << s;                    // 安全：s 在作用域结束前都有效

右值引用与移动语义

T&& 是右值引用（C++11），专门绑定即将销毁的临时对象（右值）。配合移动语义，可以把临时对象的内部资源"偷走"，避免昂贵的深拷贝——这是 std::vector、std::string 高效的关键。

C++
int&& rr = 42;          // 右值引用绑定临时值
std::string a = "hello world, this is a long string";
std::string b = std::move(a);  // std::move 把 a 标记为右值
                              // b 直接"接管"a 的内部缓冲区（零拷贝）
                              // 之后 a 处于"被移走"状态：内容未定义但可安全销毁/重新赋值

// 移动构造：临时对象进来时不再深拷贝
class MyString {
public:
    MyString(MyString&& other) noexcept      // 移动构造
        : buf_(other.buf_) { other.buf_ = nullptr; }   // 偷走指针
private:
    char* buf_;
};

// 完美转发（进阶）：把参数原样转发给另一个函数
template<typename T>
void wrapper(T&& arg) {
    target(std::forward<T>(arg));   // 保持实参的左右值属性
}
✓
移动 ≠ 零成本魔法

移动只是"把资源指针转让"，速度接近常量；但移动后源对象的状态是"有效但未指定"，只能销毁或重新赋值，不能再使用它的旧内容。只有具备资源（堆内存、文件句柄）的类才有移动价值。

指针 vs 引用：一张表分清

对比维度指针引用
是否可空可以是 nullptr，需判空必须绑定对象，天生非空
能否重新绑定可以随时改指其他对象一旦绑定终身不变
语法取地址 &、解引用 *、箭头 ->与普通变量完全一样
是否占内存是，8 字节（存地址）语言层面不占独立内存
典型用途动态内存、容器元素、可空参数、函数指针函数参数/返回值、运算符重载、迭代遍历
能否指向指针可以（多级指针）不能（无"引用数组"/"指向引用的指针"）
安全度低：野指针、悬垂、越界风险高：不判空、不重绑，更安全
经验法则：能引用就别用指针；必须表示"可能没有"（如可选参数、容器元素）或需要重新指向时才用指针。

03内存管理 Memory 分配、释放与智能指针

C++ 的优势之一是程序员可以直接控制内存，代价是必须自己负责"谁分配、谁释放"。掌握内存分区、new/delete 的配对规则，再用 RAII 与智能指针把风险降到最低。

程序内存分区

一个运行中的程序，其内存大致分为以下几个区域，理解它们就知道"变量什么时候销毁、能不能返回它的地址"。

区域存放内容生命周期
栈（stack）函数内的局部变量、函数参数、返回地址函数调用时创建、返回时自动销毁；容量小（默认几 MB），过大易栈溢出
堆（heap）new / malloc 分配的对象由程序员控制何时释放；容量大（GB 级），但手动管理易泄漏
全局 / 静态区全局变量、static 变量程序启动时创建，程序结束时销毁，全程存活
常量区字符串字面量、const 常量只读，程序结束时销毁；修改它是未定义行为
代码区编译后的机器指令只读，程序运行期间始终存在
栈上内存自动管理、速度快；堆上内存需手动管理、速度慢。这是"栈对象优先、堆对象按需"设计原则的根源。

new / delete：C++ 的分配与释放

new 在堆上分配内存并调用构造函数；delete 先调用析构函数再释放内存。核心铁律：new 与 delete 必须配对——new 配 delete，new[] 配 delete[]。

C++
#include <string>

int* p = new int(42);        // 分配一个 int，初始值 42
delete p;                    // 释放并调用析构（int 无析构，仅释放）
p = nullptr;                 // 置空防悬垂

std::string* s = new std::string("hello");
delete s;                    // 先调用 string 析构，再释放内存

int* arr = new int[100];     // 分配数组：100 个 int
arr[0] = 1;
delete[] arr;                // 必须用 delete[]，配对数组形式
arr = nullptr;

// new 失败会抛出 std::bad_alloc 异常（而不是返回 NULL）
try {
    int* big = new int[1'000'000'000];
    delete[] big;
} catch (const std::bad_alloc& e) {
    std::cerr << "内存不足" << std::endl;
}

构造 / 析构不调用构造函数和析构函数自动调用构造函数 / 析构函数
大小计算手动传字节数 sizeof(T) * n编译器自动计算
失败处理返回 NULL，需检查抛出 std::bad_alloc 异常
数组形式一次分配，无区别new[] / delete[] 单独配对
扩容realloc 可尝试原地扩无对应功能，需自己搬移
C++ 中优先用 new/delete；只有与 C 库交互（如 fopen、C 函数返回 malloc 内存）时才用 malloc/free，且谁分配谁释放。

常见内存错误

!
内存泄漏（Memory Leak）

new 了却一直不 delete，堆内存越占越多，程序越来越慢，最终可能耗尽内存。注意：指针变量本身在栈上，但指向的堆内存不会自动释放——函数返回只会丢掉"地址"，内存还在。

!
悬垂指针 / 悬垂引用

内存释放后仍通过旧地址访问。释放后置空、或改用智能指针可避免。

!
重复释放（Double Free）

同一块内存被释放两次，堆管理结构被破坏。两个裸指针指向同一对象时最容易发生。

!
越界读写（Buffer Overflow）

访问数组或指针越界，静默破坏相邻内存。C++ 不检查越界，必须靠程序员和工具（AddressSanitizer、Valgrind）把关。

!
new[] 配 delete（或反之）

配对错误导致只释放首元素或调用错误次数的析构，行为未定义。规则只有一个：用什么形式分配，就用什么形式释放。

RAII：资源获取即初始化

RAII（Resource Acquisition Is Initialization）是 C++ 管理资源的核心理念：把资源的生命周期绑定到对象的生命周期——构造函数里获取资源，析构函数里释放资源。对象离开作用域，析构函数必然执行，资源就必然释放，无论中途是否抛异常。

C++
#include <cstdio>

class File {
public:
    explicit File(const char* path)
        : fp_(std::fopen(path, "r")) {}   // 构造：获取资源

    ~File() {                              // 析构：释放资源
        if (fp_) std::fclose(fp_);
    }
    // 禁止拷贝（避免两个对象持同一文件句柄）
    File(const File&) = delete;
    File& operator=(const File&) = delete;
private:
    std::FILE* fp_;
};

void demo() {
    File f("data.txt");    // 打开文件
    // ... 中途抛出异常也没关系
}                          // 离开作用域，f 的析构自动关闭文件

// std::lock_guard、std::vector、std::string、智能指针都是 RAII 的体现：
// vector 析构时自动释放内部堆内存，你从不手动 delete 它
✓
RAII 的意义

把"释放"这件容易忘、容易错的事交给析构函数自动完成。写类时问自己：我的对象拥有什么资源？析构函数里释放了吗？拷贝会共享资源吗？—— 三个问题答清楚，资源管理就稳了。

unique_ptr：独占所有权

std::unique_ptr<T> 是"独占"智能指针：一个对象只能被一个 unique_ptr 拥有。不能拷贝，只能移动。它不引入额外开销，是裸指针的首选替代。

C++
#include <memory>

// 用 make_unique 创建（C++14），避免裸 new
std::unique_ptr<int> up = std::make_unique<int>(42);
*up = 100;                              // 用起来像指针
int v = *up;                            // 解引用

// 不能拷贝：以下会编译错误
// std::unique_ptr<int> up2 = up;

// 可以移动：所有权转移
std::unique_ptr<int> up3 = std::move(up);   // up 变为空
if (!up) { /* up 已经空了 */ }

// 放进容器
std::vector<std::unique_ptr<std::string>> vec;
vec.push_back(std::make_unique<std::string>("a"));
vec.emplace_back(std::make_unique<std::string>("b"));

// 需要裸指针时用 get()（只用于接口传递，不负责释放）
void use(int* p);
use(up3.get());

// 离开作用域自动 delete —— 不需要也不能手动释放

shared_ptr 与 weak_ptr：共享所有权

std::shared_ptr<T> 允许多个指针共享同一个对象，通过引用计数跟踪：最后一个 shared_ptr 销毁时自动释放对象。std::weak_ptr<T> 是"旁观者"：不增加引用计数，用于打破循环引用、缓存等场景。

C++
#include <memory>

std::shared_ptr<int> sp = std::make_shared<int>(10);
std::shared_ptr<int> sp2 = sp;          // 引用计数 2
std::cout << sp.use_count();            // 2

// sp 和 sp2 都离开作用域后，对象才被释放
// make_shared 一次分配（控制块+对象），比 new + shared_ptr 更高效

// weak_ptr：不增加计数
std::weak_ptr<int> wp = sp;             // 引用计数仍为 2
if (auto locked = wp.lock()) {          // lock() 返回 shared_ptr
    std::cout << *locked;               // 对象还活着，安全使用
} else {
    std::cout << "对象已被释放";         // 对象已死，不能用了
}

// weak_ptr 不能直接解引用，必须通过 lock() 提升为 shared_ptr
!
shared_ptr 的代价

引用计数是原子操作，拷贝和析构有少量开销；两倍于裸指针的内存（对象 + 控制块）；循环引用会导致内存泄漏（见下）。优先用 unique_ptr，只有确实需要共享时才用 shared_ptr。

循环引用问题

两个对象用 shared_ptr 互相持有对方，引用计数永远到不了 0，对象永远不释放——用智能指针还是泄漏了。解决方案：把其中一个方向改为 weak_ptr。

C++
#include <memory>
#include <iostream>

struct B;                    // 前向声明

struct A {
    std::shared_ptr<B> b;    // A 持有 B
    ~A() { std::cout << "~A\n"; }
};
struct B {
    std::shared_ptr<A> a;    // B 持有 A → 循环：A 和 B 都释放不了
    ~B() { std::cout << "~B\n"; }
};

// 上面代码中：main 结束后没有任何输出（析构没被调用）= 内存泄漏！

// 修正方案：让"从属方"用 weak_ptr
struct B2 {
    std::weak_ptr<A> a;      // 旁观，不增加引用计数
    ~B2() { std::cout << "~B2\n"; }
};
// 现在 A 的计数能归零，A 释放后 B2 也随之释放
✓
所有权设计原则

父子关系中：父持有子用 shared_ptr（或 unique_ptr），子回指父用 weak_ptr。一句话："谁拥有、谁用 shared_ptr/unique_ptr；只是引用一下、用 weak_ptr。"

内存管理最佳实践

  • 默认栈对象：能放栈上就不放堆上，栈对象自动析构、零泄漏风险。
  • 动态对象一律用智能指针：优先 unique_ptr，需要共享再用 shared_ptr，禁止裸 new 散落各处。
  • 用 make_* 系列：std::make_unique / std::make_shared，异常安全且更高效。
  • 谁 new 谁 delete：实在要用裸指针，保证分配与释放在同一逻辑层，并写成对称结构。
  • 删除后置空：delete p; p = nullptr; 防悬垂。
  • 返回对象别返回指针：现代 C++ 直接按值返回，配合移动语义几乎零开销。
  • 用工具验证：AddressSanitizer（编译加 -fsanitize=address）、Valgrind 可检测泄漏和越界。

04STL 容器 Containers 标准模板库的数据结构

STL（Standard Template Library，标准模板库）是 C++ 标准库的核心，提供"数据结构 + 算法 + 迭代器"一整套基础设施。选对容器，代码既简洁又高效。

STL 六大组件

组件作用示例
容器 Container存储数据的结构vector、map、set、list
算法 Algorithm对数据进行操作（查找、排序、变换）sort、find、accumulate
迭代器 Iterator统一访问容器元素的"指针"begin()、end()、rbegin()
仿函数 Function Object可调用对象，配置算法的行为std::less<>、std::greater<>
适配器 Adapter改造接口（如把 deque 变成 stack）stack、queue、priority_queue
分配器 Allocator封装内存分配策略（一般不用管）std::allocator<T>
理解"容器只存数据、算法只写逻辑、迭代器负责连接两者"是掌握 STL 的钥匙。

vector：最常用的动态数组

std::vector<T> 是连续内存的动态数组：随机访问 O(1)、尾部插入均摊 O(1)、中间插入删除 O(n)。默认容器首选。理解 size（已有元素数）与 capacity（已分配容量）是重点。

C++
#include <vector>

std::vector<int> v = {1, 2, 3};
v.push_back(4);                    // 尾部追加：{1,2,3,4}
v.emplace_back(5);                 // 原地构造追加（对大对象更高效）
v.pop_back();                      // 删除尾部

v.size();                          // 当前元素个数
v.capacity();                      // 已分配容量（≥ size）
v.reserve(100);                    // 预分配，避免反复扩容
v.shrink_to_fit();                 // 把容量收紧到 size

v[0] = 10;                         // 随机访问 O(1)，不检查越界
v.at(0);                           // 越界抛 std::out_of_range

// 遍历的三种姿势
for (size_t i = 0; i < v.size(); ++i) { /* v[i] */ }
for (int& x : v) { x *= 2; }               // 范围 for + 引用可修改
for (auto it = v.begin(); it != v.end(); ++it) { /* *it */ }

// 插入 / 删除
v.insert(v.begin() + 1, 99);       // 中间插入 O(n)
v.erase(v.begin());                // 删除首元素 O(n)
v.clear();                         // 清空（capacity 不变）
!
扩容与迭代器失效

容量不足时 vector 会重新分配一块更大的内存并搬移所有元素（通常扩容 1.5~2 倍）。这次重分配会让所有迭代器、指针、引用失效；中间插入删除也会使插入点之后的迭代器失效。事先 reserve 可避免大部分重分配。

其他序列容器

C++
#include <deque>      // 双端队列
#include <list>       // 双向链表
#include <forward_list> // 单向链表
#include <array>      // 固定大小数组

// deque：两端都能快速插入删除（O(1)），随机访问 O(1)
std::deque<int> dq = {1, 2, 3};
dq.push_front(0);        // {0,1,2,3}
dq.push_back(4);         // {0,1,2,3,4}

// list：双向链表，任意位置插入删除 O(1)，但随机访问 O(n)
std::list<int> lst = {5, 1, 4};
auto it = std::find(lst.begin(), lst.end(), 1);
lst.insert(it, 9);       // 在 1 前面插入
lst.splice(lst.begin(), lst, it);   // 把 it 结点搬到头 —— 链表独有
lst.sort();              // list 自带 sort（不能用 std::sort）

// forward_list：单向链表，省一个指针，但只能单向遍历
std::forward_list<int> fl = {1, 2, 3};

// array：固定大小，无动态分配，元素在栈上
std::array<int, 4> a = {1, 2, 3, 4};   // 比 C 数组更安全
a[0] = 9;                // 支持迭代器、size()、越界检查（at）
✓
序列容器怎么选

默认 vector；需要双端增删用 deque；需要任意位置 O(1) 插入删除且不在乎随机访问用 list；固定大小优先 array（比裸数组多安全与迭代器）。注意：list 的"插入不失效迭代器"优势只在频繁中间插入时才有价值，否则缓存不友好、性能反而差。

map / set：有序关联容器

map（键值对）、set（集合）底层是红黑树，元素按键自动排序，查找/插入/删除都是 O(log n)。multimap / multiset 允许重复键。

C++
#include <map>
#include <set>

// map：键 → 值，按键升序
std::map<std::string, int> ages;
ages["tom"] = 18;              // operator[]：键不存在则插入（默认值 0 再赋值）
ages["jack"] = 20;
ages.insert({"lucy", 19});     // 已存在则插入失败（insert 返回 pair 告知）

auto it = ages.find("tom");    // O(log n) 查找
if (it != ages.end()) {
    std::cout << it->first << ": " << it->second;   // first=键 second=值
}
ages.erase("jack");            // 按键删除

// 注意 operator[] 会"顺手插入"：查找时应该用 find / at
if (ages.count("no-such") == 0) { /* 不存在 */ }
// ages["no-such"] 这种写法会真的插入一个空值！

// set：去重 + 有序集合
std::set<int> s = {3, 1, 2, 1};   // 实际存 {1,2,3}
s.insert(0);                     // {0,1,2,3}
s.erase(3);
auto it2 = s.lower_bound(2);     // 第一个 ≥ 2 的元素

// 遍历都是有序的
for (const auto& kv : ages) { std::cout << kv.first << " "; }
!
operator[] 的坑

map[key] 在键不存在时会默认构造一个值插入。因此"只查不改"要用 find、count 或 at；at 对不存在的键抛异常。自定义类型作键需要支持 operator<（或提供比较器）。

无序容器：哈希表

unordered_map / unordered_set 底层是哈希表：查找/插入/删除平均 O(1)，但元素无序。追求查找速度、不需要有序遍历时用它。

C++
#include <unordered_map>
#include <unordered_set>

std::unordered_map<std::string, int> um;
um["apple"] = 1;
um["banana"] = 2;
auto it = um.find("apple");      // 平均 O(1)
um.erase("banana");

// 遍历顺序不确定（取决于哈希），不保证任何顺序
for (const auto& kv : um) { /* ... */ }

std::unordered_set<int> us = {5, 3, 8, 3};   // 实际存 {5,3,8}（无序）
us.insert(1);

// 自定义类型做键：需要提供 hash 函数和相等比较
struct Person { std::string name; int age; };
struct PersonHash {
    std::size_t operator()(const Person& p) const {
        return std::hash<std::string>()(p.name) ^ std::hash<int>()(p.age);
    }
};
std::unordered_set<Person, PersonHash> people;
i
性能注意

哈希表平均 O(1)，但哈希冲突多时会退化；load_factor（负载因子）超过阈值会 rehash，rehash 会使迭代器失效。可提前 reserve 预分配桶数。而 map/set 的 O(log n) 是稳定上界。

容器适配器

适配器基于其他容器改造接口，只暴露特定操作：stack（栈，LIFO）、queue（队列，FIFO）、priority_queue（优先队列，默认大顶堆）。

C++
#include <stack>
#include <queue>

// stack：后进先出
std::stack<int> st;
st.push(1); st.push(2); st.push(3);
int top = st.top();      // 3
st.pop();                // 弹出 3

// queue：先进先出
std::queue<int> q;
q.push(1); q.push(2);
int front = q.front();   // 1
q.pop();

// priority_queue：按优先级出队（默认大顶堆，最大的先出）
std::priority_queue<int> pq;
pq.push(3); pq.push(1); pq.push(4);
pq.top();                // 4 —— 最大元素

// 小顶堆：传入 greater 比较器
std::priority_queue<int, std::vector<int>, std::greater<int>> min_pq;

迭代器：容器的"通用指针"

迭代器是容器与算法之间的桥梁：算法只认迭代器接口，不关心具体容器。迭代器按能力分为五类（能力依次增强）：

迭代器种类支持操作典型容器
输入 / 输出单向读取 / 写入，一次通过istream / ostream 迭代器
前向单向往复遍历（++）forward_list、unordered_*
双向前向 + 后退（--）list、set、map
随机访问双向 + 跳跃（+n、下标、比较）vector、deque、array
迭代器种类决定能用的算法：随机访问迭代器才能 std::sort、std::binary_search；双向迭代器只能 reverse、prev/next。
C++
#include <vector>
#include <iterator>

std::vector<int> v = {1, 2, 3, 4, 5};

auto it = v.begin();        // 指向首元素
auto last = v.end();        // 尾后：最后一个元素的下一个位置，不可解引用
for (auto p = v.begin(); p != v.end(); ++p) { /* *p */ }

v.rbegin() / v.rend();      // 反向迭代器，从尾到头
std::next(it, 2);           // 前进 2 步（<iterator>）
std::prev(v.end());         // 后退 1 步
std::distance(v.begin(), v.end());   // 元素个数（随机访问为 O(1)）

// 反向遍历
for (auto rit = v.rbegin(); rit != v.rend(); ++rit) {
    std::cout << *rit;      // 5 4 3 2 1
}
!
迭代器失效

容器修改后，旧迭代器可能失效：vector/deque 的插入、删除、扩容会使相关迭代器失效；map/set/unordered_map 中，删除某个元素后，指向它的迭代器失效，但其他迭代器仍然有效。删除循环里必须用 it = container.erase(it)（erase 返回下一个迭代器）。

容器选型指南

✓
选型流程（一句话版）

默认 vector → 需要按键查找选 map/unordered_map（有序选 map，只需速度选 unordered）→ 需要两端操作选 deque → 需要频繁中间插入删除选 list → 需要去重选 set → 需要固定大小选 array。

容器随机访问插入/删除查找特点
vectorO(1)尾部 O(1)*，中间 O(n)—连续内存，缓存友好
dequeO(1)两端 O(1)，中间 O(n)—双端队列
listO(n)任意位置 O(1)—链表，迭代器不因插入失效
map / set—O(log n)O(log n)有序（红黑树）
unordered_map / set—平均 O(1)平均 O(1)无序（哈希表）
arrayO(1)不支持—固定大小，栈上
* 尾部插入均摊 O(1)；n 为容器规模。完整复杂度速查见第 06 章。

05STL 算法 Algorithms <algorithm> 与 <numeric>

STL 算法是"与容器解耦"的通用函数，用迭代器表达操作范围 [first, last)（左闭右开）。掌握常用算法，绝大多数循环都可以用一行调用替代。需要先包含 #include <algorithm> 和 #include <numeric>。

算法概览

分类代表算法
查找 / 计数find、count、all_of、any_of、search
遍历 / 变换for_each、transform、copy、fill、replace、remove
排序 / 堆sort、stable_sort、partial_sort、nth_element、make_heap
二分查找binary_search、lower_bound、upper_bound、equal_range
合并 / 集合merge、set_union、set_intersection、includes
最值 / 数值min、max、clamp、accumulate、iota、partial_sum
排列next_permutation、prev_permutation
所有算法只操作迭代器范围，不关心是 vector、list 还是数组——这就是"算法与容器解耦"。

查找与计数

C++
#include <algorithm>
#include <vector>

std::vector<int> v = {1, 5, 3, 5, 2};

// find：查找第一个匹配元素，返回迭代器；找不到返回 end()
auto it = std::find(v.begin(), v.end(), 5);
if (it != v.end()) std::cout << "找到: " << *it;

// count：统计出现次数
int n = std::count(v.begin(), v.end(), 5);        // 2

// find_if：按条件查找（lambda 见本章末尾）
auto it2 = std::find_if(v.begin(), v.end(),
                        [](int x) { return x > 3; });  // 第一个 >3 的元素

// 条件判定：全部 / 任一 / 没有
bool allBig = std::all_of(v.begin(), v.end(), [](int x){ return x > 0; });  // true
bool hasBig = std::any_of(v.begin(), v.end(), [](int x){ return x > 4; });  // true
bool noneBig = std::none_of(v.begin(), v.end(), [](int x){ return x > 9; }); // true

// 子序列搜索 / 相邻重复
std::vector<int> sub = {5, 3};
auto it3 = std::search(v.begin(), v.end(), sub.begin(), sub.end());
auto it4 = std::adjacent_find(v.begin(), v.end());   // 第一个相邻相等对

遍历与变换

C++
#include <algorithm>
#include <vector>

std::vector<int> v = {1, 2, 3, 4, 5};
std::vector<int> out(5);

// for_each：对每个元素做操作
std::for_each(v.begin(), v.end(), [](int& x){ x *= 2; });
// v = {2,4,6,8,10}

// transform：变换后写入目标（源和目标可以不同容器）
std::transform(v.begin(), v.end(), out.begin(),
               [](int x){ return x * x; });          // out = {4,16,36,64,100}

// copy：拷贝范围
std::vector<int> v2;
std::copy(v.begin(), v.end(), std::back_inserter(v2));  // 尾部追加式拷贝

// fill：填充
std::fill(v2.begin(), v2.end(), 0);

// replace：把旧值替换为新值
std::replace(v.begin(), v.end(), 4, 40);

// remove：逻辑删除 —— 把要删的值移到尾部，返回新逻辑末尾
// 真正的删除需要搭配 erase（remove-erase 惯用法）
auto new_end = std::remove(v.begin(), v.end(), 6);    // 6 移到末尾
v.erase(new_end, v.end());                            // 物理删除

// 或一行完成：
v.erase(std::remove(v.begin(), v.end(), 6), v.end());

// 其他常用：reverse 反转、rotate 旋转、unique 去重（相邻重复）
std::reverse(v.begin(), v.end());
std::rotate(v.begin(), v.begin() + 2, v.end());       // 向左旋转 2 位
std::vector<int> dup = {1,1,2,2,3};
dup.erase(std::unique(dup.begin(), dup.end()), dup.end());  // {1,2,3}
✓
remove 的真相

std::remove 不删除元素，只把"不要的"挪到末尾并返回新的逻辑末尾——必须配合 erase 才能真正缩小容器（remove-erase 惯用法）。这是 STL 面试常问考点。

排序与堆

C++
#include <algorithm>
#include <functional>

std::vector<int> v = {5, 2, 8, 1, 9, 3};

// sort：升序（不保证稳定）
std::sort(v.begin(), v.end());                    // {1,2,3,5,8,9}

// 降序：用比较器
std::sort(v.begin(), v.end(), std::greater<int>());  // {9,8,5,3,2,1}

// 自定义比较（lambda）—— 最常用
std::sort(v.begin(), v.end(), [](int a, int b){ return a > b; });

// stable_sort：稳定排序（相等元素保持原相对顺序）
std::stable_sort(v.begin(), v.end());

// partial_sort：只保证前 k 个是"最小的 k 个"（且有序）
std::partial_sort(v.begin(), v.begin() + 3, v.end());   // 前 3 小到位

// nth_element：第 k 小就位（前面都 ≤ 它，后面都 ≥ 它，但无序）
std::nth_element(v.begin(), v.begin() + 2, v.end());    // 第 3 小就在正确位置

// 堆操作：把范围当堆用（默认大顶堆）
std::make_heap(v.begin(), v.end());      // 建堆
std::push_heap(v.begin(), v.end());      // 先把新元素放末尾再调用
std::pop_heap(v.begin(), v.end());       // 堆顶移末尾，再 v.pop_back()
std::sort_heap(v.begin(), v.end());      // 堆排序（升序）
i
三者区别

sort 全排，O(n log n)；partial_sort 只排前 k 个，O(n log k)；nth_element 只让第 k 个就位，平均 O(n)——只要"第 k 大"不要完整顺序时选它，性能最好。

二分查找（要求已排序）

C++
#include <algorithm>
#include <vector>

std::vector<int> v = {1, 3, 3, 5, 7, 9};   // 必须先升序排序！

// binary_search：是否存在（返回 bool）
bool found = std::binary_search(v.begin(), v.end(), 3);   // true

// lower_bound：第一个 ≥ 目标值的位置
auto it1 = std::lower_bound(v.begin(), v.end(), 3);
// 指向第一个 3（下标 1）

// upper_bound：第一个 > 目标值的位置
auto it2 = std::upper_bound(v.begin(), v.end(), 3);
// 指向 5（下标 3）

// equal_range：同时拿到 [lower, upper)
auto range = std::equal_range(v.begin(), v.end(), 3);
// 区间 [下标1, 下标3) 内都是 3

// 经典应用：统计 3 的出现次数
int cnt = std::upper_bound(v.begin(), v.end(), 3)
        - std::lower_bound(v.begin(), v.end(), 3);       // 2

// 有序数组的"第一个 > 5 的元素"
auto it3 = std::upper_bound(v.begin(), v.end(), 5);      // 指向 7
!
前提条件

四个二分算法都要求范围已按同一比较规则排序。对未排序范围使用，结果是未定义行为。自定义比较时，排序和二分必须用同一比较器。

合并与集合运算（要求各自有序）

C++
#include <algorithm>
#include <vector>

std::vector<int> a = {1, 3, 5, 7};
std::vector<int> b = {2, 3, 6, 8};

// merge：把两个有序序列合并（结果也有序）
std::vector<int> m;
std::merge(a.begin(), a.end(), b.begin(), b.end(),
           std::back_inserter(m));            // {1,2,3,3,5,6,7,8}

// includes：a 是否包含 b 的全部元素
bool contained = std::includes(a.begin(), a.end(), b.begin(), b.end());  // false

// 集合运算（输出也是有序、去重的）
std::vector<int> out;
std::set_union(a.begin(), a.end(), b.begin(), b.end(), std::back_inserter(out));
// 并集 {1,2,3,5,6,7,8}

std::set_intersection(a.begin(), a.end(), b.begin(), b.end(), std::back_inserter(out));
// 交集 {3}

std::set_difference(a.begin(), a.end(), b.begin(), b.end(), std::back_inserter(out));
// 差集（a 有 b 没有）{1,5,7}

lambda 表达式与谓词

C++11 引入 lambda，是编写"内联回调/比较器"的最简洁方式。语法：[捕获列表](参数列表) -> 返回类型 { 函数体 }。

C++
#include <algorithm>
#include <vector>

int base = 10;
// 值捕获 [base]：拷贝一份进 lambda
auto add_base = [base](int x) { return x + base; };
// 引用捕获 [&base]：lambda 里操作的是原变量
auto bump = [&base]() { base += 1; };
// 全部捕获：= 值捕获全部，& 引用捕获全部
// 显式混合：[=, &base]（base 引用，其余值）

// 带返回类型（一般可省略，由编译器推导）
auto f = [](int x) -> double { return x * 1.5; };

// mutable：让值捕获的副本可修改（原变量不受影响）
int n = 0;
auto counter = [n]() mutable { return ++n; };

// 谓词 = 返回 bool 的可调用对象，配合算法使用
std::vector<int> v = {3, 1, 4, 1, 5};
// 按绝对值降序
std::sort(v.begin(), v.end(),
          [](int a, int b) { return std::abs(a) > std::abs(b); });
// 统计偶数个数
int even = std::count_if(v.begin(), v.end(),
                         [](int x) { return x % 2 == 0; });

// 捕获容器引用，在算法中修改
int total = 0;
std::for_each(v.begin(), v.end(), [&total](int x){ total += x; });

// 通用 lambda（C++14）
auto add_generic = [](auto a, auto b) { return a + b; };
✓
lambda 是语法糖

lambda 本质是一个匿名函数对象（仿函数），编译器自动生成类并实现 operator()。捕获变量会变成它的成员。需要长期保存时可以用 std::function<返回(参数)> 包装。
