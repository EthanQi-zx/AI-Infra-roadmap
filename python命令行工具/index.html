logtool 是一个单文件的 Python 命令行工具：统计日志级别、筛选错误、关键字检索，并支持批量重命名、改后缀与清理文件。无需安装任何依赖，下载即可运行。

Features

两大能力，六条命令

日志分析帮你快速读懂日志，文件处理帮你批量打理目录，所有操作都可先预览、后执行。

Σ

日志级别统计

统计 DEBUG 至 FATAL 全级别分布与总行数，一眼看清日志的严重程度构成。

精准挑出 ERROR / CRITICAL / FATAL 行并附带行号，快速定位问题现场。

#

关键字检索

大小写不敏感的关键字匹配，可限制输出行数，排查"timeout"这类高频问题很顺手。

文件批量处理

递归匹配目录：批量重命名、统一修改后缀、批量清理，一条命令搞定。

安全 文件类操作全部支持 --dry-run 预览；删除文件必须显式加 -f 才真正执行，误操作风险降到最低。
Commands

命令文档

两级子命令结构：log 处理日志，file 处理文件。运行 python logtool.py --help 可随时查看帮助。

log 日志分析：统计、筛选、检索
log stats <file>
file 日志文件路径
统计日志文件的总行数与各级别（DEBUG / INFO / WARN / ERROR / CRITICAL / FATAL）出现次数，按数量从高到低输出。
log error <file>
file 日志文件路径
筛选并输出 ERROR、CRITICAL、FATAL 三种错误级日志，每行附带原始行号，结尾汇总错误总数。
log grep <file> -k <keyword> -n <limit>
file 日志文件路径-k 匹配关键字-n 限制输出行数
按关键字匹配日志行（大小写不敏感），带行号输出；用 -n 可限制最大输出条数。
file 文件批量处理：重命名、改后缀、清理
file rename <dir> -r <OLD> <NEW> -p <pattern>
dir 目录路径-r 旧字符串 → 新字符串-p 匹配模式--dry-run 仅预览
递归查找目录下匹配的文件，将文件名中的旧字符串替换为新字符串；加 --dry-run 只打印预览不改名。
file ext <dir> -e <.ext> -p <pattern>
dir 目录路径-e 新后缀（如 .log）-p 匹配模式--dry-run 仅预览
批量统一修改文件后缀（支持省略点号自动补全），例如把一批 .txt 统一改为 .log。
file clean <dir> -f -p <pattern>
dir 目录路径-f 真正删除-p 匹配模式--dry-run 仅预览
批量删除匹配的文件。必须显式加 -f 才会真正删除；不加则只列出待删除项，配合 --dry-run 可安全预览。
提示：文件匹配基于递归搜索（rglob），-p 支持 *.txt 等通配符。删除与改名都是不可逆操作，养成先加 --dry-run 预览的习惯。
Quick Start

三步上手

整个工具只有一个文件，没有任何安装步骤。

获取工具

将 logtool.py 放入你的项目目录，或直接使用仓库自带的 app.log 示例日志体验。

$ python logtool.py --help

分析日志

统计级别分布、筛选错误、检索关键字，三分钟读懂一份日志。

$ python logtool.py log error app.log
5: ... ERROR timeout when calling api
8: ... CRITICAL db connection lost
总计: 4 条错误日志

批量处理文件

先预览、再执行，批量重命名与改后缀同样简单。

$ python logtool.py file ext . -e .log -p "*.txt" --dry-run
[预览]: readme.txt -> readme.log
